MATCHING ALGORITHM LOGIC
================================================================================

The fuzzy matching algorithm scores items based on:

1. Title Similarity (3 points):
   - Contains substring (case-insensitive)
   - Common word matching

2. Category Match (2 points):
   - Exact category match

3. Location Match (1-2 points):
   - Full location match: 2 points
   - Partial word match: 1 point

Threshold: Items with score ≥ 3 are considered probable matches

Example:
  Lost: "Blue iPhone 13" (Electronics, Library 2nd Floor)
  Found: "iPhone 13 Pro Blue" (Electronics, Library)
  → Score: 3 (title) + 2 (category) + 1 (location) = 6 (HIGH MATCH!)

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Failed to connect to database"
Fix: Check MySQL is running, database exists, credentials correct

Issue: "JavaFX runtime components are missing"
Fix: Ensure --module-path points to JavaFX SDK lib folder

Issue: "Class not found"
Fix: Ensure MySQL JDBC JAR is in classpath (-cp flag)

Issue: Chat not updating
Fix: Polling runs every 3 seconds, ensure database connection stable
